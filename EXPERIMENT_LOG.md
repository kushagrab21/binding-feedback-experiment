# Experiment Log — Binding Feedback Experiment

This log is the single source of truth for what was built, in what order, and with
what evidence. It compares **advisory** vs **binding** feedback in LLM agent harnesses.

## Logging standard

Every step appends one entry. Each entry MUST contain:

- **Step ID / date** — the phase.step identifier (e.g. `1.1`) and the date.
- **What was built** — a concrete description of the artifacts created or changed.
- **Provenance** — where the artifacts came from (hand-written, generated by a
  script, derived from a seed, etc.), enough to reproduce them.
- **Evidence of correctness** — raw command output (not a claim of success) showing
  the artifacts do what they should. Paste the actual terminal output.
- **Worked example** — one concrete end-to-end example exercising the artifact.
- **Decisions / surprises** — design decisions made, alternatives rejected, and
  anything unexpected encountered.

Infrastructure only: the harness/tooling is built here; experimental episodes and
task-solving are never performed by the builder.
